# MkDocs Material로 팀 문서 사이트 만들기: 빌드, 엄격 모드, 로컬 미리보기

마크다운 파일 몇 개를 MkDocs Material로 정적 사이트로 빌드하고, 깨진 링크를 --strict 옵션으로 잡고, mkdocs serve로 미리 봅니다. 문서를 코드처럼 저장소에서 관리하는 방식의 최소 구성을 실행 결과로 확인합니다.
