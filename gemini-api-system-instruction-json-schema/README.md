# Gemini API 시스템 지시와 JSON 스키마 출력: 로컬 모델과 같은 질문으로 비교

Gemini API에 시스템 지시와 temperature를 주어 말투를 고정하고, pydantic 클래스로 JSON 출력 형식을 지정합니다. 앞선 로컬 모델 글과 같은 질문을 보내 날짜와 장소 추출 결과가 어떻게 다른지 확인합니다.

글: https://copyandrun.com/blog/gemini-api-system-instruction-json-schema/

## 파일

- `sys_more.py`
- `system_json.py`

## 사용 방법

글의 순서대로 이 폴더에서 명령을 실행합니다.

연습용 코드입니다. 취약한 예제와 실습용 비밀번호가 들어 있으므로 운영 환경에 쓰지 않습니다. 개인키와 비밀번호 파일은 포함하지 않았습니다.
