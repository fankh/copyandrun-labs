# restic으로 암호화 백업 만들기: 증가분 저장, 복원 검증, 손상 감지까지

오픈소스 백업 도구 restic을 도커로 실행해 암호화 저장소를 만들고, 두 번째 백업에서 바뀐 부분만 저장되는지, 복원본이 원본과 같은지, 저장소 파일 일부를 일부러 망가뜨렸을 때 어떤 점검이 잡는지 확인합니다.

글의 순서대로 이 폴더에서 명령을 실행합니다.
