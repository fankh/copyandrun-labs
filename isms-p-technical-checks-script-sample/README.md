# ISMS-P 기술 점검 항목 일부를 스크립트로 확인해 양호, 취약, 수동확인 표 만들기

일부러 허술하게 만든 nginx 시험 서버에서 계정 관리, 접근 로그의 권한과 보관 기간, TLS 버전, 저장 데이터 암호화를 파이썬 스크립트로 점검해 표를 만들고, 설정을 고친 뒤 취약 8건이 양호로 바뀌는 것을 확인합니다. 참고용 자동 점검이며 인증 심사를 대신하지 않습니다.
