# Pandoc으로 마크다운을 Word와 HTML로 바꾸기: 한글 문서 변환 확인

마크다운 보고서를 pandoc/core 이미지로 docx와 html로 변환하고, docx를 압축 해제해 제목, 표, 굵은 글씨가 들어갔는지 확인합니다. PDF 변환은 LaTeX가 없어 실패한 결과 그대로 기록합니다.
